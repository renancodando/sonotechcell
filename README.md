## Executar
Abra `index.html` no navegador ou use `python3 -m http.server 3000`.

## Funcionalidades
Menu responsivo, animações preservadas, detalhes de serviços em modais, mapa sob demanda, rotas, ligações e formulário de diagnóstico que prepara uma mensagem no WhatsApp. O cliente confirma o envio; nenhum dado é armazenado no site.

Dados comerciais: `script.js` (objeto `business`) e marcações de `index.html`. O formulário emite o evento `cscell:diagnosis`.

O arquivo `assets/celular-realista.png` e a identidade gráfica original foram mantidos no próprio repositório; nenhuma mídia é carregada de outro repositório.
